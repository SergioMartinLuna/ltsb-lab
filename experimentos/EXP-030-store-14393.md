# EXP-030 — Microsoft Store en 14393

Estado: **definido**. No ejecutado.

## Hipotesis

Windows 10 LTSB 2016 (build 14393) **no incluye** Microsoft Store, ni la carpeta `WindowsApps`, ni
los cmdlets de Appx funcionan con la misma firma que en builds posteriores.

## Metodo

Instrumento: el bloque `appx` del inventario base (`docs/05` §8), mas el bloque `canales`. Todo de
solo lectura.

```powershell
# 1. ¿Existe el paquete del Store?
Get-AppxPackage -Name Microsoft.WindowsStore -AllUsers -EA SilentlyContinue |
    Select-Object Name, Version, InstallLocation

# 2. ¿Cuántos paquetes hay en total?
Get-AppxPackage -AllUsers | Measure-Object | Select-Object Count
Get-AppxPackage | Select-Object Name, Version, Status | Sort-Object Name

# 3. ¿Existe la carpeta de paquetes?
Test-Path "$env:ProgramFiles\WindowsApps"
Get-ChildItem "$env:ProgramFiles\WindowsApps" -EA SilentlyContinue |
    Select-Object Name, CreationTime

# 4. ¿Qué firma real tienen los cmdlets?  <- resuelve la ambigüedad de docs/04 §5
Get-Command Add-AppxPackage  -Syntax
Get-Command Remove-AppxPackage -Syntax
Get-Command Get-AppxProvisionedPackage -Syntax
Get-Module -ListAvailable Appx | Select-Object Name, Version, Path

# 5. ¿Existe msixmgr (MSIX Core)?
Get-ChildItem -Path C:\ -Filter msixmgr.exe -Recurse -EA SilentlyContinue
```

El paso 4 es el mas importante: la documentacion consultada en `docs/04` §5 usaba el moniker
`windowsserver2016-ps`, que es de **Windows Server 2016**, no de Windows 10 build 14393. Era un proxy,
no una prueba. Este paso produce el valor real.

Ademas, capturar el contenido de la sintaxis permite verificar si existen `-SkipLicense`,
`-AllowUnsigned` y `-ExternalLocation` en esta build concreta, que es lo que la referencia oficial no
permite afirmar.

## Criterio de decision

Escrito antes de ejecutar:

| Resultado | Evidencia | Conclusion |
|---|---|---|
| `STORE_AUSENTE` | sin paquete del Store y `WindowsApps` vacio o inexistente | Confirma `docs/04` §9 `[COMUNIDAD]`. El Store se desinstalo de la imagen de LTSC |
| `STORE_PRESENTE` | el paquete existe | **Refutaria `docs/04` §9.** Corregir y reanalizar |
| `CMDLETS_LIMITADOS` | la sintaxis no expone `-SkipLicense` / `-AllowUnsigned` | La instalacion de paquetes firmados puede fallar por licencia |

Los tres pueden ser ciertos a la vez. Se registran por separado, no como un veredicto unico.
